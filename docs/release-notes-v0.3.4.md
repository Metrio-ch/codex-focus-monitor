# Codex Focus Monitor v0.3.4 — macOS 预览版

用于 Codex 项目跟进与注意力聚焦的顶部悬浮小工具。最多三个任务、一个当前焦点，提供本轮计时、状态提示和人工确认的停靠恢复点。

## 下载和安装

下载与电脑架构一致的 DMG 和对应的 `.sha256` 文件。当前发布包为 **Apple Silicon / arm64**，未提供经过验证的 Intel 包。应用包声明的最低系统版本为 macOS 13，旧系统兼容性尚未逐版验证。

在下载目录验证文件完整性：

```bash
shasum -a 256 -c Codex-Focus-Monitor-0.3.4-macOS-arm64.dmg.sha256
```

打开 DMG，将 `Kayla Monitor.app` 拖入 `Applications`，然后从“应用程序”启动。仓库采用新名称，应用名称与原有数据目录保持兼容。

**本包仅有 ad-hoc 签名，未经 Apple Developer ID 签名与公证。** macOS 可能阻止首次打开；请确认来源、核对校验值，并阅读 [Apple 的安全说明](https://support.apple.com/102445)。不希望运行未公证应用时，可审阅源码后自行构建。不要关闭系统安全防护。

拖拽安装不会修改全局 hooks。需要范围外活动监听时，可按照 README 单独选择完整安装。此工具非 OpenAI 官方产品。

## 本版变化

- 提供可重复运行的 DMG 打包入口及 SHA-256 校验文件（不承诺不同构建产物逐字节一致）。
- 对发布二进制进行构建路径映射并剥离调试信息，防止泄露开发者本机路径。
- 补充标准 `/Applications/Codex.app` 和当前用户 Applications 目录的 CLI 查找路径。
- 保留 v0.3.3 的增量事件读取、重复事件保护及活动时间单调更新。
- **疑似停滞阈值仍为 15 分钟，现有文案不变。**

## 隐私和限制

已在构建主机通过 23 项核心自检、3 项 hooks 配置测试、DMG 只读挂载、包内 helper 自检、签名完整性及 SHA-256 校验。未在全新 Mac 或 Intel Mac 上完成首次安装实测。

安装包不包含开发者的运行状态、对话日志、凭证或备份。应用会在本机保存有限摘录与恢复点；历史事件中的有限摘录暂不自动清理。

状态依赖本地日志格式和可识别事件，不是权威任务接口；长工具调用等情况仍可能出现无活动提示。恢复点通过本地文本规则提炼，需要人工确认。详情见 README。
